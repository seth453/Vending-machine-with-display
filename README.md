# Raspberry Pi Vending Machine

A fully functional vending machine prototype combining hardware, software, user interaction, and embedded control using a Raspberry Pi.

# Overview

This project implements a vending machine system from the hardware level through the application level.

The system was designed to accept user selections, process transactions, control the physical machine, and provide feedback through a display.

The project demonstrates the interaction between software and physical hardware using a Raspberry Pi.

# System Components

- Raspberry Pi
- Display
- User input controls
- Hardware interfaces
- Vending mechanism

# Key Features

- Product selection
- User interface through a display
- Transaction processing
- Hardware control
- Software-to-hardware communication
- Real-time user feedback


The goal was to create a complete system rather than an isolated software program.
The project required coordinating physical hardware, low-level interfaces, application logic, and a user-facing interface into one working system.
